# 📊 Sales Forecasting Dashboard

## Overview

This project is an interactive Sales Forecasting Dashboard developed using **Python**, **Streamlit**, **Machine Learning**, and **Data Analytics**. It analyzes historical Superstore sales data, forecasts future sales using XGBoost, detects anomalies, and segments products based on demand patterns.

---

## Features

### 📈 Sales Overview
- Total Sales by Year
- Monthly Sales Trend
- Region and Category Filters
- Filtered Sales Table
- Sales by Category Chart

### 🔮 Forecast Explorer
- Forecast by Category or Region
- Forecast Horizon (1–3 Months)
- XGBoost Sales Forecast
- Model Performance (MAE & RMSE)

### 🚨 Anomaly Report
- Isolation Forest Anomaly Detection
- Z-Score Based Anomaly Detection
- Tables of Detected Anomalies

### 📦 Product Demand Segments
- K-Means Clustering
- PCA Visualization
- Demand Segment Table
- Cluster Summary
